# Another custom chat plugin
plugin for custom chat in minecraft 1.21.11


* Support prefix and sufix for messages and colorized text
* messages delivering to all players connected to server

builded by using flatpak org.freedesktop.Sdk.Extension.openjdk21-25.08

build command :
```
JAVA_HOME=/usr/lib/sdk/openjdk21/jvm/openjdk-21 /usr/lib/sdk/openjdk21/gradle/bin/gradle shadowJar --warning-mode all
```
